# Mr. Hisham | Connect Plus English

This repository contains a static GitHub Pages website for **Mr. Hisham Fadil**, an experienced ELA teacher supporting Grades 3-6 students using the Connect Plus English curriculum.

Live site:

```text
https://mrhishamfadil.github.io/teacher-ai-workspace/
```

## What the site includes

- Home page with teacher branding and grade selector.
- Grade 3, Grade 4, Grade 5, and Grade 6 unit pages.
- Real unit titles supplied for the Connect Plus curriculum structure.
- Writing feedback placeholder page for enrolled students.
- About page with teacher biography and contact placeholders.
- Static HTML, CSS, and small JavaScript only.

## What it does not include

- No login system.
- No database.
- No backend.
- No payment system.
- No textbook scans or copied textbook pages.
- No affiliation claim with McGraw-Hill.

## Editing notes for Mr. Hisham

To update a lesson later:

1. Open the correct grade page, such as `grade-5.html`.
2. Find the unit card you want.
3. Replace the placeholder YouTube link, worksheet link, or revision notes link.
4. Keep explanations original and teacher-created.

## Copyright and safety

- Use original teacher-created summaries, worksheets, and explanations.
- Do not upload full textbook PDFs.
- Do not copy textbook pages or answer keys.
- Keep student writing submissions out of the public repository.
- The website footer states: "Content is original and teacher-created. Not affiliated with or endorsed by McGraw-Hill."
