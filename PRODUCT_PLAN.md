# Smart Path Study Hub Product Plan

## MVP goal

Create a simple static study hub for Grades 3 to 6 that a teacher can publish for free on GitHub Pages.

The MVP should prove the manual content workflow before adding automation.

## Target users

- Grade 3 to Grade 6 students who need lesson revision support.
- Parents who want clear links and simple guidance.
- A teacher who wants a low-cost publishing workflow.

## Core features

- Home page with grade links.
- Grade pages organized by unit.
- One complete sample lesson.
- One weekly revision sample.
- Writing practice page.
- JSON lesson metadata.
- Beginner-safe automation preparation folder.

## Future agents

Future automation could include:

- Lesson draft generator.
- Weekly revision generator.
- Worksheet idea generator.
- Quiz draft generator.
- Writing feedback draft assistant.
- Teacher approval assistant.

## Low-cost architecture

- GitHub Pages for hosting.
- Static HTML, CSS, and small JavaScript.
- JSON for lesson metadata.
- Google Sheets later for private planning.
- GitHub Actions later for draft generation.
- Google Forms later for writing submissions.

## Monetization options

Only consider monetization after the free workflow is useful and trusted.

Possible future options:

- Paid printable worksheet packs.
- Small-group revision sessions.
- Parent subscription for extra practice.
- School licensing for teacher-reviewed content.
- Premium teacher dashboard later, only if needed.
