About this MVP

Smart Path Study Hub is a simple, low-cost foundation for curriculum-aligned learning support.

What this site does now

This MVP organizes study support by grade, unit, and lesson. It includes placeholder lessons, a complete Grade 5 sample lesson, a weekly revision sample, and a writing practice page.

All content is original placeholder material. A teacher should review every real lesson before publishing it for students.

Copyright safety

  • Do not upload full textbook PDFs.
  • Do not copy textbook pages or answer keys.
  • Write original explanations in your own teacher voice.
  • Create curriculum-aligned but original worksheets.
  • Link only to videos and resources you are allowed to share.

Student privacy safety

  • Do not publish student names, emails, grades, or private submissions.
  • Do not store student personal data in this public repository.
  • Use Google Forms or another private tool later if submissions are needed.
  • Teacher approval should happen before any future feedback is sent to students.

Simple architecture

  • Static HTML pages
  • Shared CSS design
  • Small JavaScript menu helper
  • JSON lesson metadata
  • GitHub Pages hosting
